🏗️ ARQUITECTURA DEL SISTEMA
================================================================================

FLUJO DE DATOS:
Frontend (Vanilla JS)
   ↓ HTTP fetch (JSON)
Google Apps Script (API REST)
   ↓ Lectura/escritura
Google Sheets (Base de Datos)

ENDPOINTS DISPONIBLES:
  GET /vendedores              - Lista de vendedores
  GET /productos               - Productos únicos
  GET /tamanos?producto=X      - Tamaños de un producto
  GET /opciones?p=X&t=Y        - Impresiones y materiales
  POST /buscar-producto        - Buscar precio exacto
  GET /condiciones?producto=X  - Términos y condiciones
  GET /configuracion           - Parámetros del sistema
  GET /historial?vendedor=X    - Historial de cotizaciones
  POST /guardar-cotizacion     - Guardar nueva cotización

HOJAS DE GOOGLE SHEETS:
  • BaseDatos      - Catálogo de productos (12 columnas, fórmulas)
  • Vendedores     - Lista de prevendedores (3 columnas)
  • Condiciones    - Términos por artículo (2 columnas)
  • Configuracion  - Parámetros del sistema (6 filas)
  • Historial      - Registro de cotizaciones (6 columnas, auto-llenado)

================================================================================
🚀 PASOS PARA EMPEZAR (RESUMEN)
================================================================================

TIEMPO TOTAL: 30-45 minutos

1. CREAR GOOGLE SHEETS (15 min)
   → Seguir: personalizados-eb-web/docs/GOOGLE_SHEETS_SETUP.md
   → Copiar tu Spreadsheet ID

2. CONFIGURAR GOOGLE APPS SCRIPT (10 min)
   → Copiar Code.gs a tu Google Apps Script
   → Reemplazar TU_SPREADSHEET_ID_AQUI
   → Desplegar como Web App
   → Copiar tu Script ID

3. CONFIGURAR FRONTEND (2 min)
   → Abrir: personalizados-eb-web/js/config.js
   → Reemplazar YOUR_SCRIPT_ID_HERE con tu Script ID

4. DESPLEGAR EN NETLIFY (5 min)
   → Opción: GitHub + Netlify
   → Opción: Drag & drop en Netlify.com

5. PROBAR (5 min)
   → Abre tu URL
   → Login, agrega producto, genera PDF

→ INSTRUCCIONES DETALLADAS: Ver INSTRUCCIONES_INICIO.md
